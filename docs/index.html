Text, documents, and notes. One terminal.

TextLT is a native C++ terminal workspace for editing documents, organizing notes, and reusing text. Keep related work together in Projects and transform text locally with built-in or Lua processors.

Edit, organize, and reuse text

Use Documents (Docs) for your files, Notes for ideas and drafts, and Actions for text you’ll need again.

⌨

Edit files in Docs

Work with plain text or open source files with syntax highlighting. Right-click a selection to change its case, adjust indentation, or find the same text.

✎

Draft in Notes

Keep project notes in groups. Format headings and lists from the right-click menu, and give longer drafts room in two or three columns.

⎘

Copy from Actions

Save messages, checklists, or commands in named blocks. Click a caption or choose it from the context menu to copy the whole block.

▤

Find your files

Browse folders in the Files dialog, then use the sidebar to jump between projects, open files, and favorites.

🎨

Preview a theme while you edit

Browse light and dark palettes in the theme picker. See how each one colors the file you already have open.

⚙

Make shortcuts your own

Look up menu and editing shortcuts, change the bindings you use most, or reset a shortcut to its default.

Install

Install TextLT

Choose Linux x64, Windows x64, or macOS on Apple Silicon. Copy the commands into your terminal to download and run the installer for your platform.

Selected

Linux installer

Downloads the Linux installer script and runs it. The script downloads the release archive, installs TextLT into your home directory, and creates the launcher.

Open release GitHub repository

Linux
Run the installer in Bash. It puts the launcher in ~/.local/bin.
Windows
Run the commands in PowerShell. The installer adds the TextLT launcher to your user PATH.
macOS
The installer uses the Apple Silicon (arm64) release archive.
