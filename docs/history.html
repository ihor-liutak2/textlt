The Story of TextLT

From a lightweight terminal editor to an independent workspace for documents, notes, and reusable text.

TextLT began with a practical idea. Editing text in a terminal should feel familiar, with menus, shortcuts, and direct selection. That same idea now guides a local-first workspace for creating, organizing, and transforming text, while keeping documents portable and under the user’s control.

Development timeline

Dates follow the project’s commits and version tags.

  1. June 13, 2026

    A lightweight terminal editor

    The earliest recorded commit contains a native C++ editor built with FTXUI. It already includes file browsing, familiar clipboard shortcuts, and keyboard and mouse selection. Undo and redo, search and replace, and syntax highlighting followed that day.

  2. June 14–22, 2026

    A workspace for everyday editing

    JSON themes and file favorites made the editor easier to make your own. The sidebar gained an open files list and Save All, followed by recent files. Menus and dialogs kept these tools within reach.

  3. June 14–25, 2026

    Git enters the workspace

    Git support began in the status bar and file sidebar on June 14. On June 25, a repository dialog brought everyday Git actions into the editor.

  4. June 20, 2026

    Early distribution and the first site file

    The v0.2.0 tag points to a June 20 commit. A release workflow added AppImage packaging, and the first site index served as a registry directory.

  5. June 24, 2026

    The application is split into components

    June refactoring separated editing operations from the editor component, then split the application implementation across source files. This made room for more focused changes to editing, file handling, and the interface.

  6. June 26–July 5, 2026

    Reusable text transformations

    The Lua processor engine included scripts for tasks such as normalizing spaces and unwrapping lines. Later changes added built-in processors and tools to edit and manage custom processors, so a cleanup could be applied again without repeating each edit.

  7. June 26–July 3, 2026

    Text from more document formats

    Import work began with DOCX and FB2 and expanded to ODT and RTF. Import brought text from document containers into the editor for further editing and processing.

  8. July 1–18, 2026

    Editing beyond the local machine

    The first remote-file implementation appeared July 1. Remote connection management continued to evolve through the July 18 tag v0.9.3. Remote file access extends the editing workflow to machines such as servers and virtual machines.

  9. July 4–6, 2026

    A public installation guide

    The July 4 tag v0.9.1 was followed by a product landing page on July 5 with platform-specific installation guidance. Standalone website installer scripts followed on July 6.

  10. July 7–8, 2026

    Documents, sessions, and views gain clearer roles

    The July refactor clarified how the workspace binds documents to panes, gave document sessions a central role in runtime state, and separated viewport state from the document. File state, input routing, and processor targeting also gained clearer owners.

  11. July 23, 2026

    Notes join the editor

    A dedicated Notes workspace introduced note documents, storage, and editing sessions. The change is included in the July 23 tag v0.9.5.

  12. November 3–23, 2026

    From v0.9.7 to v1.0.0

    v0.9.7 was tagged on November 3 and documented use on Linux and Windows Subsystem for Linux. Folder-based projects arrived in v0.9.8 on November 13, and v0.9.9 on November 20 included Markdown import for Notes. The November 23 tag v1.0.0 improved how projects reconnect to matching Notes and Actions groups.

Working with text today

TextLT brings editing, personal notes, and repeatable text work into a lightweight terminal workspace. Plain text and Markdown keep information portable across tools and operating systems.

▤

Documents

Browse files, switch between open documents, and keep related files in projects. Use familiar keyboard shortcuts and mouse controls to edit.

✎

Notes and reusable text

Group working notes and drafts around a project. Keep frequently used messages and snippets in Actions so they’re easy to find and copy.

⚙

Processing and import

Apply built-in transformations, write a reusable Lua processor, or bring text in from other document formats.
