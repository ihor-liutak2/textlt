# TextLT 1.1.0

- **Connect** adds direct text and file transfers between paired TextLT devices. Each device creates a persistent local identity. Exchange pairing codes to verify the other device, then start the TextLT provider from the sidebar. Paired TextLT devices can also exchange Notes and Actions snapshots.
- **LocalSend** adds HTTPS text and file transfers with LocalSend peers. Start it independently from the sidebar, refresh discovery, or connect by a peer's IPv4 address. Diagnostics shows usable IPv4 addresses and explains Windows and WSL reachability.
- **Docs** adds a horizontal scrollbar for long lines when Smart Word Wrap is off.
- **Git Logs** adds independent horizontal scrollbars for branches, commits, and commit details. The local branches column has 15 more terminal cells when space allows.

## Installation

Release packages target Linux x64, Windows x64, and macOS Apple Silicon. Follow the [installation instructions](https://github.com/ihor-liutak2/textlt/blob/v1.1.0/README.md#install-from-release). Upgrading preserves user configuration, Connect identities and pairings, and installed Piper/TTS voices.

Start with [the Connect guide](https://github.com/ihor-liutak2/textlt/blob/v1.1.0/connect/README.md) to pair devices or set up LocalSend.
