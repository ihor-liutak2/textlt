# TextLT 1.1.1

- **Workspace layout** refreshes the main menu, sidebar controls, and the
  Actions, Notes, and Connect workspaces.
- **Open files** adds a document bar for switching between open files.

## Installation

Release packages target Linux x64, Windows x64, and macOS Apple Silicon:

- Linux: `textlt-linux-x64.tar.gz` and `TextLT-x86_64.AppImage`
- Windows: `textlt-windows-x64.zip`
- macOS Apple Silicon: `textlt-macos-arm64.tar.gz`

Follow the [installation instructions](https://github.com/ihor-liutak2/textlt/blob/v1.1.1/README.md#install-from-release).
Upgrading preserves user configuration, Connect identities and pairings, and
installed Piper/TTS voices.
