Everything You Need to Work with Text

A native terminal workspace for documents, notes, and powerful text actions.

TextLT brings document editing, personal information, and reusable text tools together in a lightweight C++ application. Work with local files, choose your own settings, and connect to other systems when your work calls for it.

  • ▤ Documents Your documents. Your workspace.
  • ✎ Notes Capture ideas. Organize information.
  • ⎘ Actions Do more with your text.

Documents

Create and edit local text files in Docs. Browse folders, reopen recent files, pin favorites, and switch between open documents from the sidebar.

  • Assign open documents to a single editor pane or a two- or three-column layout.
  • Find and replace within a file, search from the current sidebar folder, and use syntax highlighting when editing source or configuration files.
  • Import text from DOCX, ODT, OTT, RTF, FB2, and zipped FB2 files.
  • Open a remote file in the same editor and upload the saved copy when you’re ready.

Notes

Keep ideas, research, reminders, and drafts in a dedicated workspace. Browse by group, sort by title or date, and search note titles and content. Find or replace text inside an open note, and restore deleted notes from Trash.

  • Import Markdown and organize notes with headings, paragraphs, lists, and checklists.
  • Use two or three columns for longer notes. Assign menu shortcuts for creating, editing, and formatting notes.
  • Notes are stored as local .tlnote files in the platform’s app data directory. On Linux, XDG_DATA_HOME can set the data root.

Actions

Save reusable text as Actions cards. Organize cards into groups and pages, and give each card up to four separately labeled blocks. Click a label or use the context menu to copy a block for pasting into a document or another app.

Text Processors

Use the separate Text Processors tool to transform document text. Use the built-in Trim trailing spaces processor or unwrap imported lines with a configurable minimum line length. Use the Custom Processor Builder to validate, save, and manage reusable Lua processors with parameters.

One Project. One Unified Workspace.

Bring your documents, notes, actions, and remote resources together.

Register an existing folder with Add Project or Add Current Folder as Project. Select a project in the sidebar to switch the folder and Git context and bring its Notes and Actions groups into reach. TextLT saves the project name, folder, optional connection, and active selection locally in projects.json.

Project

A named workspace rooted in a local folder

  • Documents

    Browse and search files from the project folder.

  • Notes

    Keep drafts and reference notes in a dedicated group.

  • Actions

    Keep reusable text cards on pages in a project group.

  • Remote connection

    Assign a saved connection and open its files from the project.

When you register a new project, TextLT can relink an existing same-name Notes group and merge matching Actions groups. Use Set/Change Connection in the Project menu to assign a remote connection.

Ways to use projects

  • Software development. Keep source files with technical notes, release snippets, and a connection to a remote server.
  • Scientific research. Keep research documents and observation notes together, with reusable text blocks and processors for cleaning up imported material.
  • Technical documentation. Keep drafts, reference notes, and boilerplate in reach, and use Text Processors for consistent formatting.
  • Personal projects. Give each project its own folder, working notes, and reusable checklists or messages.

Built for the Terminal

TextLT uses C++ and FTXUI to provide a native, local terminal interface. Type directly in the editor, navigate by keyboard, or use mouse selection, menus, and dialogs. The editor supports UTF-8 text. Use Distraction Mode to hide workspace controls and focus on the document.

Intelligent Text Tools

Optional Tools → Quick AI works on selected text or the current paragraph in Docs and open notes. Choose Standard, Fluency, Humanize, Formal, Academic, Simple, or Creative to guide the revision.

Enable Translate to choose a target language and either select the source language or use Auto detect. Review the result, then choose Change to replace the source text or Copy Result to use the revision elsewhere.

In Tools → AI Settings, select and activate a model from a local Ollama server or a configured external provider. The provider tabs include OpenCode, ChatGPT through the Codex CLI, Claude, and MiMo. Available models and effort settings depend on the provider. External providers receive the text you submit.

Listen to Your Text

Listen to an open document with local Piper speech synthesis on a supported setup. The Windows build of the speech helper lacks the persistent Piper backend. Use the Run tab in Tools → TTS to prepare the selected document and start at the cursor. Use Play, Pause, Stop, or Next to listen through its sections.

Tools → TTS Settings can fetch the voice registry, install Piper where a runtime package is available, and download, test, or delete voices. Browse the registry by language and save a voice for the selected document in the TTS Voice tab. The Library manages prepared documents and cached audio.

Work Beyond Your Local Files

Configure SFTP through an OpenSSH host alias, FTP over TLS (FTPS) with explicit or implicit TLS, or Dropbox with a token file. Browse directories and copy files between the local and remote panels.

Open remote text in Docs through a local cached copy. Save your edits locally, then choose Sync Last in Remote Files when you’re ready to upload the saved copy.

Version Control Within Your Workspace

Open Tools → Git to inspect repository status and history, review diffs, stage or unstage files, and commit changes. Create and switch branches, compare revisions side by side or as a unified diff, and fetch or push using a configured remote. Git Settings provides controls for remote URLs and commit identity.

Your Terminal. Your Workflow.

Keyboard Shortcuts and Terminal Compatibility

Open Help → Keyboard Shortcuts to assign bindings in Menu shortcuts and Text shortcuts. Set shortcuts for document commands, note creation and formatting, Actions commands, or editor movement and selection. TextLT stores bindings in shortcuts.json and can reset them individually or together. The editor rejects terminal-reserved combinations and Ctrl+Alt bindings. Shift-only text bindings are limited to navigation keys and Tab.

Appearance and Themes

Preview a bundled light or dark palette in Options → Theme, or load a custom JSON theme. Help → Theme Color Settings lets you adjust and save editor, interface, dialog, and button colors using named colors or hex values. Theme files can define syntax highlighting colors. Editor options include line numbers, smart word wrap, and tab size.
